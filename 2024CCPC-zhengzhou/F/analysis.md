# F. 优秀字符串 — 题解

## 算法标签
模拟、字符串

## 关键观察
- 一个字符串是否为优秀字符串只依赖其前 $5$ 个字符，且长度必须严格等于 $5$。
- 「前四个字符互不相同」可以用 `set` 去重或两两比较实现，由于只有 $4$ 个字符，常数极小。
- 「第三个字符与第五个字符相同」即下标（$0$-based）$2$ 与下标 $4$ 相等。

## 思路
1. 读入 $n$ 个字符串，对每个串独立判断；
2. 先看长度是否为 $5$，否则跳过；
3. 再看 $S[2] = S[4]$ 是否成立；
4. 最后判断 $\{S[0], S[1], S[2], S[3]\}$ 这四个字符两两不同（等价于放进 `set` 后大小为 $4$）。

满足三条则计数 $+1$，最后输出计数。

## 实现要点
- 使用快速 IO（`ios::sync_with_stdio(false)`）防止读入开销；
- 字符串下标使用 $0$-based：题面「第 $3$ 个 / 第 $5$ 个」对应 $S[2]$ / $S[4]$，「前 $4$ 个」对应 $S[0..3]$；
- 字符集包含字母（区分大小写）与数字，不要 `tolower`；
- 四个字符互不相同可以直接展开 $\binom{4}{2}=6$ 次比较，也可以丢进 `set<char>`。

## 复杂度
- 时间：$O\!\left(\sum |S_i|\right)$（每个串只看前几个字符，整体线性于输入规模）
- 空间：$O(1)$ 额外空间

## 易错点
- 长度不是 $5$ 的串（更短或更长）必须先排除，否则 `S[4]` 越界；
- 前四个字符互不相同包含 $S[2]$，不要漏掉与 $S[0], S[1], S[3]$ 的比较；
- 题面要求「前四个字符互不相同」，不要错误地把 $S[4]$ 也加入去重判断（$S[4]=S[2]$ 是允许的，事实上恰恰要求相等）。
