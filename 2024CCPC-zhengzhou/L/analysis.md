# L. Toxel 与 PCPC II — 题解

## 算法标签
DP、段长上界剪枝

## 关键观察
- **每次操作的 $i$ 一定恰好等于本次所修最后一个 bug 的行号 $a_j$**：若选更大的 $i$，运行代价线性增加且不带来任何收益；若选更小，则覆盖不到 $a_j$。因此一次操作的运行代价就是「本次最右侧 bug 的行号 $a_j$」。
- 把所有操作按时间排序，由于每次操作 $i = a_j$，每个 bug 只会在「包含它的最早一次操作」中被修复。所以可以把 $m$ 个 bug 切成若干个**连续区间**（按行号顺序），每个区间 $(k, j]$ 对应一次操作，代价 $a_j + (j - k)^4$。
- **每段 bug 数 $x \le 22$**：若某段 $x \ge 23$，将其拆成两半 $\lceil x/2\rceil, \lfloor x/2\rfloor$，修复代价由 $x^4$ 降为 $\le 2(x/2)^4 = x^4/8$，节省 $\ge 7x^4/8$；而新增一次操作至多多花 $n \le 2 \times 10^5$ 秒。当 $x \ge 22$ 时 $7x^4/8 > 2 \times 10^5$（$7 \cdot 22^4 / 8 \approx 2.05 \times 10^5$），拆分严格更优。所以最优分割中每段 $\le 22$。

## 思路
1. 把问题等价为：将 $m$ 个 bug 按顺序划分成若干连续段 $(k_0=0, k_1] (k_1, k_2] \dots (k_{t-1}, k_t=m]$，每段 $(k, j]$ 的代价是 $a_j + (j - k)^4$，求总代价最小。
2. 设 $dp[j]$ 表示「修完前 $j$ 个 bug」的最小代价。转移：
   $$dp[j] = \min_{0 \le k < j} \big( dp[k] + a_j + (j - k)^4 \big), \quad dp[0] = 0.$$
3. 由「每段 $\le 22$」可把内层 $k$ 的范围缩到 $[\max(0, j - K), j - 1]$，取 $K = 22$（实现里为安全留余量取 $K = 30$ 或更大也行）。复杂度 $O(mK)$，$m = 2 \times 10^5$、$K \le 30$ 时只有 $6 \times 10^6$ 次基本运算，远比 1s 时限宽松。
4. 答案即 $dp[m]$。

## 实现要点
- 数组下标从 $1$ 开始，方便表达 $a_j$；$dp[0] = 0$ 是「还没修任何 bug」的状态。
- 内层循环 `for (int k = max(0, j - K); k < j; ++k)`，先把 $a_j$ 拎到循环外做一次加法，循环内只算 $dp[k] + (\text{len})^4$。
- $(\text{len})^4$ 直接用 `ll d = j - k; ll d2 = d * d; ll d4 = d2 * d2;`，$len \le 30$ 时绝对不溢出。
- `dp[j]` 用 `long long` 即可：每段代价 $\le a_m + 22^4 \le 2 \times 10^5 + 2.3 \times 10^5 < 5 \times 10^5$，共至多 $m$ 段，所以 $dp[m] \le 5 \times 10^5 \cdot m = 10^{11}$，安全。
- 初始 `dp[j] = LLONG_MAX / 4` 或 `1e18`，避免转移时 `dp[k] + ...` 溢出。
- 单组数据，无需多组重置。

## 复杂度
- 时间：$O(m \cdot K)$，$K = 22$（实现取 30 留余量），约 $6 \times 10^6$。
- 空间：$O(m)$。

## 易错点
- 段长上界写成 $K = 22$ 时是「**段长**」上界，对应内层 $k$ 范围是 $[j-22, j-1]$，写循环时不要把 $K$ 当成「内层循环次数」少写一格。
- $dp$ 初始化要够大但不能溢出：用 `LLONG_MAX` 直接加任何正数都会溢出 UB，建议 `1e18` 或 `LLONG_MAX / 4`。
- 误把 $i$ 取得更大或更小：本题运行长度 $i$ 必然等于本次最右 bug 行号 $a_j$，是把转移化简的关键。
- 不要把 $dp$ 状态错设成「修完前 $i$ **行**」——这样状态数有 $n$ 个、转移要枚举上次的「行号」，复杂度难以收敛；必须以「修完前 $j$ 个 **bug**」作为状态。
