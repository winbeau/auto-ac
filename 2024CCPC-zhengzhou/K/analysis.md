# K. 树上问题 — 题解

## 算法标签
换根 DP、树形 DP

## 关键观察
- 对每条无向边 $(u, v)$，无论以谁为根，它都会被定向成「父 → 子」。若 $u$ 是父、$v$ 是子，则约束为 $a_v \ge \dfrac{a_u}{2}$，即 $2 a_v \ge a_u$。
- 因此每条无向边天然产生两个潜在的有向约束：「$u\to v$ 合法 $\iff 2 a_v \ge a_u$」与「$v\to u$ 合法 $\iff 2 a_u \ge a_v$」。
- 每条边只可能在 $0/1/2$ 个方向上「坏掉」，这与根的选择无关，可预处理。
- 节点 $r$ 是美丽节点 $\iff$ 把所有边从 $r$ 出发向外定向（即每条边按「远离 $r$」方向）后，每条有向约束都满足，即「坏边」总数为 $0$。
- 为避免实数/整除歧义，统一用 $2 a_v \ge a_u$ 这种乘法形式判定。

## 思路
1. **预处理边方向合法性。** 对每条无向边 $(u, v)$，提前算两个布尔：`ok_uv = (2*a[v] >= a[u])`（父 $u$ → 子 $v$ 合法）、`ok_vu = (2*a[u] >= a[v])`（父 $v$ → 子 $u$ 合法）。
2. **第一次 DFS（以 $1$ 为根）。** 设 $\text{bad}[u]$ 为「以 $u$ 为根时，整棵树坏掉的边数」。当根为 $1$ 时：

   $$\text{bad}[1] = \sum_{(u,v)\in E,\ u=\mathrm{parent}(v)} [\,2 a_v < a_u\,].$$

   一遍 DFS 求出即可。
3. **换根。** 把根从 $u$ 换到它的邻居 $v$，变化的只有边 $(u, v)$ 的方向：原本 $u$ 是父、$v$ 是子，现在反过来。所以：

   $$\text{bad}[v] = \text{bad}[u] - [\,2 a_v < a_u\,] + [\,2 a_u < a_v\,].$$

   第二次 DFS 按父→子顺序，用上式从父亲推每个儿子的总坏边数。
4. **统计。** 美丽节点数即 $\#\{r : \text{bad}[r] = 0\}$。

## 实现要点
- 多组数据：邻接表、$a$ 数组、$\text{bad}$ 数组每组开头清空（或按 $n$ 截断）。
- 用迭代 DFS（显式栈）避免链状树（$n = 10^5$）爆递归栈。
- 用 `int` 即可：$a_i \le 10^6$，$2 a_i \le 2 \cdot 10^6$，远不溢出。
- 判定一律用 `2*a[x] >= a[y]` 这种乘法形式，不写浮点 / 不写 `a/2`。

## 复杂度
- 时间：每组 $O(n)$；总计 $O(\sum n)$。
- 空间：$O(n)$。

## 易错点
- 把「$a_v \ge a_u / 2$」写成 `a[v] >= a[u] / 2` 会因整除丢掉 0.5（例如 $a_u = 3, a_v = 1$：$1 \ge 1$ 误判为满足，实际 $1 < 1.5$ 不满足）。必须用 $2 a_v \ge a_u$。
- 链状数据递归 DFS 容易爆栈，要么手动开栈，要么改迭代。
- 多组数据忘记清空邻接表会把上一组的边带进来。
- $n = 1$ 时无边，答案为 $1$。
