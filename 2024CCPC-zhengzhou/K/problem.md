# K. 树上问题

## 题目来源
2024 CCPC 郑州站 · K

## 限制
- 时间限制：1000 ms
- 空间限制：1 GB

## 题目描述
378QAQ 有一棵由 $n$ 个节点组成的无根树，节点编号从 $1$ 到 $n$，每个节点有一个正整数点权。

378QAQ 认为一个节点是**美丽节点**，当且仅当该节点作为根时，对于除根节点以外的所有节点，其点权都**不小于**其父亲节点的点权的 $\dfrac{1}{2}$。

请你计算出有多少个节点是美丽节点。

## 输入格式
本题测试点包含多组数据。

第一行包含一个正整数 $t$（$1 \le t \le 10^4$），表示数据组数。

对于每组数据：

- 第一行包含一个正整数 $n$（$1 \le n \le 10^5$），表示节点数量。
- 第二行包含 $n$ 个正整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^6$），表示编号为 $i$ 的节点点权。
- 之后 $n - 1$ 行，每行包含两个正整数 $u, v$（$1 \le u, v \le n,\ u \ne v$），表示无根树中存在一条连接节点 $u$ 和节点 $v$ 的边。

保证单个测试点中所有数据的 $\sum n \le 10^5$。

## 输出格式
对于每组数据，输出一个非负整数，代表美丽节点的数量。

## 样例

### 样例 1
输入：
```
3
3
1 2 3
1 2
2 3
5
3 2 2 2 1
1 2
3 1
4 1
1 5
8
699 673 592 276 600 343 369 374
7 6
8 5
4 6
7 1
7 2
1 8
4 3
```
输出：
```
3
1
7
```
说明：

对于第二组数据，只有节点 $5$ 是美丽节点。当节点 $5$ 作为根时：

- 节点 $1$ 的父亲为节点 $5$，有 $3 \ge \dfrac{1}{2}$，满足。
- 节点 $2, 3, 4$ 的父亲为节点 $1$，均有 $2 \ge \dfrac{3}{2}$，满足。

其余节点作为根时，节点 $5$ 的父亲始终为节点 $1$，而 $1 < \dfrac{3}{2}$，不满足。

## 数据范围
- $1 \le t \le 10^4$
- $1 \le n \le 10^5$
- $1 \le a_i \le 10^6$
- $\sum n \le 10^5$
