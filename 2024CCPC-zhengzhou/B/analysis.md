# B. 扫雷 1 — 题解

## 算法标签
贪心、反悔贪心、优先队列（大根堆）

## 关键观察
- 观察 1：进入第 $i$ 轮时，累计获得的扫雷币恰为 $i$ 枚。因此选择一组购买事件 $(i_1, i_2, \ldots, i_k)$（允许重复，单价 $c_{i_j}$）合法，当且仅当对**所有前缀** $p$，$\sum_{i_j \le p} c_{i_j} \le p$。
- 观察 2：硬币只能"攒着用"而不会过期，所以扫描到第 $i$ 轮时，只能从 $\{c_1, \ldots, c_i\}$ 里选，且当前总花费 $\le i$。
- 观察 3：若已选集合在某时刻总花费 $\le i$，把集合里某个 $c_x$ 替换成更便宜的 $c_y$（$y \le i$）后总花费只会变小，可行性保持，因此**反悔（替换贵的为便宜的）总是安全的**。
- 观察 4：同一轮 $i$ 可以购买**任意多次**（单价都是 $c_i$），所以扫描到第 $i$ 轮时要"贪心地能买就买"，每次买一个 $c_i$。

## 思路
反悔贪心：按 $i$ 从 $1$ 到 $n$ 顺序扫描，维护一个大根堆 `heap`，存放当前已购的所有探测器单价，以及当前余额 `bal = i - sum(heap)`。在第 $i$ 轮反复执行：

1. 若 `bal >= c_i`：直接买一个 $c_i$，`heap.push(c_i)`，`bal -= c_i`，答案 $+1$。
2. 否则若 `heap` 非空且**堆顶 > $c_i$**：把堆顶弹出、$c_i$ 压入，相当于"把曾经买的最贵的那次反悔成在第 $i$ 轮买便宜的"。总数不变，但 `bal` 增加 `(堆顶 - c_i) > 0`，可能让接下来的购买成为可能，所以继续循环。
3. 否则跳出，进入第 $i+1$ 轮。

每个 $c_i$ 至多被压入、弹出堆各一次（替换之后弹出的元素就不会再进堆），所以堆操作总数 $O(n)$。

## 实现要点
- 用 `priority_queue<long long>` 作大根堆。
- 余额 `bal` 用 `long long`：$c_i$ 之和可达 $2 \times 10^{14}$。
- 内层"while 能买 / 能换则继续"循环：买入步骤要先于替换步骤检查。
- 替换条件用 `>` 而非 `>=`，否则 $\text{top} = c_i$ 时会无限循环。
- 单组数据，无需重置。

## 复杂度
- 时间：$O(n \log n)$。每个元素最多入堆一次、出堆一次。
- 空间：$O(n)$。

## 易错点
- 忘记"同一轮可买多次"，把内循环写成 `if` → 样例 2 / 大量小 $c_i$ 用例错。
- 余额或总花费用 `int` 溢出（$c_i$ 之和最大 $2 \times 10^{14}$）。
- 替换条件用 `>=` 而非 `>`，导致 $\text{top} = c_i$ 时反复换造成死循环。
