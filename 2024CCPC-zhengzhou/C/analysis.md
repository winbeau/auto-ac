# C. 中二病也要打比赛 — 题解

## 算法标签
DP、LIS、区间合并、树状数组

## 关键观察
- 对每个出现在 $A$ 中的值 $v$，$f(v)$ 必须取一个固定的常数 $c_v$（因为 $f$ 是函数，对同一输入只能输出同一值）。对不在 $A$ 中出现的 $x$，可以直接取 $f(x) = x$，不贡献代价。
- 因此代价 = $|\{v \in A : c_v \neq v\}|$ = （$A$ 中不同值的个数） $-$ （满足 $c_v = v$ 的不同值的个数）。要最小化代价，等价于**最大化保持 $c_v = v$ 的不同值的个数**。
- 记 $L_v$、$R_v$ 为值 $v$ 在 $A$ 中第一次/最后一次出现的位置。$B$ 单调不降意味着：若 $L_u < R_v$，则 $c_u \le c_v$；若两值"交错"（$L_u < L_v \le R_u$ 或对称），则 $c_u = c_v$。
- 将每个 $v$ 看作一段位置区间 $[L_v, R_v]$，对这些区间做"重叠合并"得到若干**连通块**。同一连通块内所有值共享同一个 $c$ 值；不同连通块按位置顺序排列，对应的 $c$ 必须**非降**。

## 思路
1. 一个连通块里最多只能"保留"（让 $c_v = v$）**一个**值——多于一个就要求同一 $c$ 等于多个不同的 $v$，矛盾。
2. 按位置顺序得到连通块序列 $C_1, C_2, \ldots, C_m$，每个 $C_i$ 包含一个值集合 $V_i$。问题变成：依次从每个连通块中**至多选一个**值，组成一个**严格递增**的子序列，最大化长度（不选某些连通块也允许）。
3. 这是带"分组约束"的 LIS。处理顺序按连通块编号，块内的值要"同时更新"以避免在同一块内连续选两个：先对块内每个值 $v$ 计算 $\text{new\_dp}[v] = 1 + \max_{v' < v} \text{dp}[v']$（查询时 Fenwick 中尚未包含本块的值），再把整块的更新一次性写回。
4. 答案 $= |\{\text{distinct values in } A\}| - \max_v \text{dp}[v]$。

## 实现要点
- $L_v$、$R_v$：扫一遍 $A$ 即可。
- 区间合并：沿位置 $1 \dots n$ 推进，每次遇到 $L_v = i$ 的值 $v$ 就加入当前块，并把当前块右端点更新为 $\max(\text{right}, R_v)$；当 $i$ 到达 $\text{right}$ 时，本块结束。
- 树状数组维护**前缀最大值**：`update(v, val)` 与 `query(v-1)`。块内先批量算 `new_dp`，再批量 `update`，杜绝块内自更新。
- 注意 $v$ 的取值范围是 $[1, n]$，Fenwick 大小开 $n+1$ 即可。

## 复杂度
- 时间：$O(n \log n)$
- 空间：$O(n)$

## 易错点
- 同一块内若按顺序边查询边更新，会把块内已选的值也算进去，产生"同块选多个"的错误增长。
- 不出现在 $A$ 中的值不计入代价，所以分母是"不同出现值的个数"，不是 $n$。
- 区间合并要按"右端点最大值"扩展，不能只看相邻区间。
