# C. 中二病也要打比赛

## 题目来源
2024 CCPC 郑州站 · C

## 限制
- 时间限制：2000 ms
- 空间限制：1 GB

## 题目描述
小鸟游六花发现了一串数字序列 $A$，包含 $n$ 个元素，每个元素 $A_i$ 是 $1$ 到 $n$ 之间的整数。她希望通过一个函数 $f$ 将 $A$ 转化成另一个序列 $B$，其中 $f$ 的定义域与值域均为 $[1, n] \cap \mathbb{Z}$，$B_i = f(A_i)$。

要求 $B$ 是**单调不降**序列。使用该魔法的代价定义为 $[1, n] \cap \mathbb{Z}$ 中满足 $f(x) \neq x$ 的 $x$ 的数量。

请帮助六花找到使 $B$ 单调不降的函数 $f$，并求出最小代价。

## 输入格式
- 第一行：一个整数 $n$（$1 \le n \le 2 \times 10^5$），代表序列长度。
- 第二行：$n$ 个整数 $A_1, A_2, \ldots, A_n$（$1 \le A_i \le n$）。

## 输出格式
- 一行，一个整数，表示最小代价。

## 样例

### 样例 1
输入：
```
10
1 10 2 6 10 8 9 4 4 5
```
输出：
```
4
```
说明：
可以选择 $f = [1, 2, 3, 4, 5, 2, 7, 2, 2, 2]$（第 $i$ 个数字 $c_i$ 表示 $f(i) = c_i$），得到的 $B = [1, 2, 2, 2, 2, 2, 2, 4, 4, 5]$，单调不降。由于 $f(6) \neq 6$、$f(8) \neq 8$、$f(9) \neq 9$、$f(10) \neq 10$，所以代价为 $4$。可以证明没有比 $4$ 更小的代价。

## 数据范围
- $1 \le n \le 2 \times 10^5$
- $1 \le A_i \le n$
