# G. 扫雷 2

## 题目来源
2024 CCPC 郑州站 · G

## 限制
- 时间限制：1000 ms
- 空间限制：256 MB

## 题目描述
T0xel 喜欢玩扫雷，但是他不喜欢数字 $2$。

他想构造一个 $n \times n$ 的扫雷地图，其中有 $m$ 个雷，并且 **没有一个空地周围恰有 $2$ 个雷**。

形式化地：构造一个 $n \times n$ 的 01 方阵，其中 $0$ 表示空地、$1$ 表示雷，恰好含有 $m$ 个 $1$，且不存在一个值为 $0$ 的格子，使得它周围 $8$ 个相邻格（曼哈顿/切比雪夫意义下相邻，即上、下、左、右、四个对角）中恰有 $2$ 个 $1$。

特别地：
- 边上的 $0$ 周围只有 $5$ 个相邻格，这 $5$ 个格中不能恰有 $2$ 个 $1$；
- 角上的 $0$ 周围只有 $3$ 个相邻格，这 $3$ 个格中不能恰有 $2$ 个 $1$。

## 输入格式
本题测试点包含多组数据。

第一行一个正整数 $T$（$1 \le T \le 100$），表示数据组数。

每组数据一行，两个整数 $n$、$m$（$5 \le n \le 1000$，$1 \le m \le n \times n$），表示地图大小和雷数。

保证单个测试点所有数据的 $\sum n^2 \le 10^6$。

## 输出格式
对于每组数据：
- 若有解，先输出一行 `Yes`，然后输出 $n$ 行，每行 $n$ 个字符（$0$ 或 $1$），表示构造的方阵。
- 若无解，输出一行 `No`。

如有多解，输出任意一种即可。

## 样例

### 样例 1
输入：
```
2
5 2
5 17
```
输出：
```
Yes
10000
00000
00000
10000
00000
Yes
11111
10001
10101
10001
11111
```
说明：

题面给出的输出仅是一种合法构造，其它合法构造（例如本题解程序输出的方阵）也会被接受。

## 数据范围
- $1 \le T \le 100$
- $5 \le n \le 1000$
- $1 \le m \le n^2$
- $\sum n^2 \le 10^6$

## 备注
- 多解可行，只需构造任意一种合法方案。
- 在给定范围内总存在合法构造（即不会出现 `No`）。
