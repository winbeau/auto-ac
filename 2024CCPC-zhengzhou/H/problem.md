# H. 随机栈

## 题目来源
2024 CCPC 郑州站 · H

## 限制
- 时间限制：1000 ms
- 空间限制：256 MB

## 题目描述
Toxel 获得了一个随机的"栈"。这个栈可被视为一个多重集 $S$，从一个非空的随机栈 $S$ 中取出一个元素时，有可能从中取出任何一个元素，其中每个元素被取出的概率是相等的。取出该元素后，该元素会从集合中删除。

以 $\{1, 2, 2\}$ 为例，有 $\tfrac{1}{3}$ 的概率取出 $1$，使得集合变为 $\{2, 2\}$；有 $\tfrac{2}{3}$ 的概率取出 $2$，使得集合变为 $\{1, 2\}$。每次取出元素的事件相互独立。

Toxel 正在对这个集合做一些操作。集合初始时为空，它总共进行了 $2n$ 次操作，其中 $n$ 次操作为插入，$n$ 次操作为取出。现在，Toxel 告诉了你它操作的顺序以及每次插入的数，且保证每次取出时，集合非空。

Toxel 想知道，如果把每次取出的数排成一个序列，那么这个序列**单调不降**的概率是多少（即每一项小于等于它的后一项）？答案对 $998\,244\,353$ 取模。

## 输入格式
第一行包含一个整数 $n$（$1 \le n \le 2 \times 10^5$）。

第二行包含 $2n$ 个整数 $a_1, a_2, \ldots, a_{2n}$（$-1 \le a_i \le n$），表示 Toxel 操作的序列。其中，若 $0 \le a_i \le n$，表示向集合中插入了 $a_i$；否则 $a_i = -1$，表示从集合中取出了一个元素。数据保证取出元素时集合非空，且插入和取出操作的次数分别恰好为 $n$。

## 输出格式
输出一行一个整数，表示答案对 $998\,244\,353$ 取模的结果。

形式化地：设 $M = 998\,244\,353$。答案可表示为既约分数 $\tfrac{p}{q}$，其中 $q \not\equiv 0 \pmod{M}$；输出满足 $0 \le x < M$ 且 $x \cdot q \equiv p \pmod{M}$ 的整数 $x$。

## 样例

### 样例 1
输入：
```
2
1 2 -1 -1
```
输出：
```
499122177
```
说明：先 push 1、push 2，集合 $\{1,2\}$。第一次取出有 $\tfrac{1}{2}$ 取到 $1$（合法）、$\tfrac{1}{2}$ 取到 $2$（不合法）。故答案为 $\tfrac{1}{2}$，对 $998244353$ 取模得 $499122177$。

### 样例 2
输入：
```
3
1 2 -1 -1 1 -1
```
输出：
```
0
```
说明：在第二个 $1$ 被插入之前，必须先取出 $1$ 和 $2$，但取出 $2$ 后再取出 $1$ 已经使序列不再单调不降；故概率为 $0$。

### 样例 3
输入：
```
4
1 -1 2 -1 3 -1 4 -1
```
输出：
```
1
```
说明：每次取出时集合中只有一个元素，取出序列必为 $1,2,3,4$，概率为 $1$。

## 数据范围
- $1 \le n \le 2 \times 10^5$
- $-1 \le a_i \le n$
- 恰好 $n$ 次插入、$n$ 次取出，且每次取出时集合非空。

## 备注
- 答案在模 $998\,244\,353$ 意义下；使用费马小定理求逆元 $a^{-1} \equiv a^{M-2} \pmod{M}$。
