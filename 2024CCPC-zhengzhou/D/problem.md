# D. 距离之比

## 题目来源
2024 CCPC 郑州站 · D

## 限制
- 时间限制：1000 ms
- 空间限制：1 GB

## 题目描述
对于 $\mathbb{R}^2$ 平面上的两个点 $P(x_P, y_P)$ 与 $Q(x_Q, y_Q)$，$PQ$ 之间的曼哈顿距离定义为

$$\lVert PQ \rVert_1 = |x_P - x_Q| + |y_P - y_Q|$$

而 $PQ$ 之间的欧几里得距离定义为

$$\lVert PQ \rVert_2 = \sqrt{(x_P - x_Q)^2 + (y_P - y_Q)^2}$$

现在给出平面上互不重合的 $n$ 个点 $P_1, P_2, \ldots, P_n$，请求出

$$\max_{1 \le i < j \le n} \frac{\lVert P_i P_j \rVert_1}{\lVert P_i P_j \rVert_2}$$

## 输入格式
**本题测试点包含多组数据。**

第一行，一个正整数 $T$（$1 \le T \le 10^5$），表示数据组数。

对于每组数据：

第一行，一个正整数 $n$（$2 \le n \le 2 \times 10^5$），表示平面上的点数。

接下来 $n$ 行，每行两个整数 $x_i, y_i$（$-10^9 \le x_i \le 10^9$，$-10^9 \le y_i \le 10^9$），表示点 $P_i(x_i, y_i)$。

保证对于单个测试点有 $\sum n \le 2 \times 10^5$。

## 输出格式
对于每组数据：输出一行，一个实数，表示点对之间曼哈顿距离与欧几里得距离之比的最大值。当你的答案与标准答案的相对误差或绝对误差不超过 $10^{-9}$ 时将视为正确答案。

## 样例

### 样例 1
输入：
```
2
2
0 0
0 1
3
1 1
2 3
5 8
```
输出：
```
1.000000000000
1.371988681140
```
说明：
- 对于第一个样例，$P_1(0,0)$, $P_2(0,1)$，$\frac{\lVert P_1 P_2 \rVert_1}{\lVert P_1 P_2 \rVert_2} = 1$。
- 对于第二个样例，最优点对为 $(P_2, P_3)$，比值为 $\frac{8}{\sqrt{34}} \approx 1.37198868$。

## 数据范围
- $1 \le T \le 10^5$
- $2 \le n \le 2 \times 10^5$
- $-10^9 \le x_i, y_i \le 10^9$
- 保证给定的 $n$ 个点互不重合
- 单个测试点 $\sum n \le 2 \times 10^5$
- 精度：相对或绝对误差 $\le 10^{-9}$ 视为正确

## 备注
- 多组数据，注意输出精度
