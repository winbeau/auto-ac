# `problem.md` 模板

每道题的题面文件统一使用如下结构。若某字段在原 PDF 中缺失，保留小标题并写 `-` 占位，不要直接删字段。

```markdown
# X. <题目标题>

## 题目来源
2024 CCPC 郑州站 · X

## 限制
- 时间限制：1000 ms
- 空间限制：256 MB

## 题目描述
<题面正文，保留必要的数学公式，使用 KaTeX/MathJax 语法：$a + b = c$>

## 输入格式
<逐行 / 逐参数说明>

## 输出格式
<逐行说明>

## 样例

### 样例 1
输入：
```
3
1 2 3
```
输出：
```
6
```
说明：
<可选，对样例的解释>

### 样例 2
…

## 数据范围
- $1 \le n \le 10^5$
- $1 \le a_i \le 10^9$
- 保证 …

## 备注
- 子任务 / 部分分（如有）
- 题目附图：见 `img/fig-1.png`
```

## 约定

- 标题里的字母与目录名一致（`X` = `A`/`B`/…）
- 公式优先 KaTeX 行内 / 行间，不直接贴 PDF 截图
- 输入输出代码块语言留空（不写 ```cpp）
- 中文题面优先；若是英文原题，可在最上方放原文，再附 `## 中文翻译`
